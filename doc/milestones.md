# Milestones

## Milestone 0: Estructuras base del problema

1. Producto interno (PMV 0). Se entregará una biblioteca de código paquetizada con las clases del dominio.

2. Se considerará válido si se ha seguido la metodología de diseño dirigido por el dominio (Domain Driven Design) a partir de la [HU001](doc/historias_usuario.md). Se comprobará en el pull request de la siguiente forma:

- Los issues registrados documentan y deciden expresamente si cada concepto abordado es una **Entidad** o un **Objeto Valor**.
- Los commits de código referencian correctamente el número de issue que están resolviendo.

## Milestone 1: Extractor y procesador de ejercicios

1. Producto interno (PMV 1). Se entregará una librería de funciones que se apoya en las clases del hito anterior. Este paquete de código debe resolver los issues orientados a avanzar en la [HU002](doc/historias_usuario.md).

2. Se considerará válido cuando este código supere una serie de tests automáticos, demostrando que es capaz de procesar el texto y aplicar la lógica correctamente sin romperse.
